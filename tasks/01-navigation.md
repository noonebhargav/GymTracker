# Phase 1: Navigation Shell

**Status:** completed

## Goal
Replace the current Stack navigator with a 5-tab bottom navigator. Each tab shows only its title text.

## Dependencies
- None (starting point)

## Acceptance Criteria
- [x] Bottom tab bar visible with 5 tabs: Workout, Routine, Explore, History, Settings
- [x] Tapping a tab switches to that tab's screen
- [x] Each screen displays its title text
- [x] Tab bar has appropriate icons

## Technical Notes
- Tab bar component from `react-native-reusables`
- Icons from `lucide-react-native`
- File-based routing via Expo Router
